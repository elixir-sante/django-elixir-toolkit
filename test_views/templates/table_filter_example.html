Exemple 5: Avec attributs data-search (champs cachés)

Ce tableau utilise l'attribut data-search sur les lignes pour inclure des informations cachées dans la recherche.

{% ui_table css_classes="is-striped is-fullwidth" filterable=True filter_target="#search-data-search" %} Nom Type Ville Boulangerie Martin Commerce Paris Restaurant Le Bistro Restauration Lyon Hôtel de la Mer Hébergement Marseille Café des Arts Restauration Paris Librairie du Sud Commerce Toulouse Cave à Vin Commerce Bordeaux {% end_ui_table %}

Essayez : 75 (trouvera les établissements à Paris), ile-de-france (trouvera les établissements en Île-de-France), restauration (trouvera par type), lyon (trouvera par ville visible)

Exemple 6: Plusieurs champs de filtre (logique ET)

Utilisez plusieurs champs pour filtrer simultanément. Les filtres s'additionnent avec une logique ET.

{% ui_table css_classes="is-striped is-fullwidth" filterable=True filter_target="#multi-filter-nom, #multi-filter-ville, #multi-filter-type" %} Nom Type Ville Boulangerie Martin Commerce Paris Restaurant Le Bistro Restauration Lyon Hôtel de la Mer Hébergement Marseille Café des Arts Restauration Paris Librairie du Sud Commerce Toulouse Cave à Vin Commerce Bordeaux Boulangerie Dupont Commerce Paris {% end_ui_table %}

Exemples : Nom: "Boulangerie", Ville: "Paris" → Trouvera les boulangeries à Paris, Type: "Commerce", Ville: "Paris" → Trouvera tous les commerces à Paris, Nom: "Café", Type: "Restauration" → Trouvera le Café des Arts

Exemple 7: Filtres par cases à cocher

Sélectionnez les types d'établissements à afficher (logique OU entre les cases cochées).

{% ui_table css_classes="is-striped is-fullwidth" filterable=True filter_target=".filter-checkbox-ex7" %} Nom Type Ville Boulangerie Martin Commerce Paris Restaurant Le Bistro Restauration Lyon Hôtel de la Mer Hébergement Marseille Café des Arts Restauration Paris Librairie du Sud Commerce Toulouse Cave à Vin Commerce Bordeaux Boulangerie Dupont Commerce Paris {% end_ui_table %}

Exemples (logique OU entre checkboxes) : Cochez "Commerce" et "Restauration" → Affiche les commerces OU les restaurants, Cochez uniquement "Commerce" → Seuls les commerces s'affichent, Décochez tout → Tous les établissements s'affichent (aucun filtre actif)
