Tableau avec lignes expandables

Fonctionnement : Le tableau utilise des lignes avec la classe table-row-expandable pour les lignes principales et table-row-details pour les lignes de détails (masquées par défaut avec style="display: none;"). Chaque ligne expandable a un attribut data-target pointant vers l'ID de la ligne de détails. Les boutons d'expansion ont la classe expand-toggle et le même data-target. Le JavaScript en bas de page gère le basculement des détails et le changement d'icônes.

Exemple 1 : Bouton avec libellé

{{ item.sku }}
