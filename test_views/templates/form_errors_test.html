Erreurs globales (non_field_errors)

Les erreurs ajoutées via form.add_error(None, ...) sont rendues automatiquement par {{ "{% crispy form %}" }} dans un article.message.is-danger placé au-dessus du formulaire (cf. ci-dessous). Le formulaire de démo en produit deux.

Formulaire avec erreurs sur tous les champs

Le formulaire est chargé avec des données volontairement invalides : chaque type de champ échoue (champ requis, format email/URL/date, min/max, longueur maximale) et les erreurs globales s'affichent en haut du formulaire. Soumettez-le pour tester la validation réelle côté serveur.
