Messages avec contenu HTML

Par défaut, is_safe=False, donc le contenu HTML est échappé. Pour afficher du HTML, utilisez is_safe=True.

{% ui_message content="Lorem ipsum dolor sit amet, consectetur adipiscing elit. Pellentesque risus mi, tempus quis placerat ut, porta nec nulla. Vestibulum rhoncus ac ex sit amet fringilla. Nullam gravida purus diam, et dictum felis venenatis efficitur." is_safe=True %} {% ui_message_info content="Message avec italique, gras, et un lien." is_safe=True %} {% ui_message_success content="
  • Élément 1
  • Élément 2
  • Élément 3
" is_safe=True %}

Messages avec contenu HTML (is_safe=True)

Par défaut (is_safe=False), le contenu HTML est échappé. Utilisez is_safe=True pour rendre du HTML de confiance.

{% ui_message content="Ce texte devrait être en gras mais il ne le sera pas (mode sécurisé par défaut)." %} {% ui_message_info content="Italiques qui ne seront pas rendus (mode sécurisé par défaut)." %} {% ui_message_danger content=" Ce script ne sera pas exécuté (mode sécurisé par défaut)." %}
