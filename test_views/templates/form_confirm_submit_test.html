Validation HTML5 native

Tous les formulaires sur cette page utilisent la validation HTML5 native du navigateur.

Si un champ obligatoire (required) n'est pas rempli ou ne respecte pas les contraintes (minlength, min, max, etc.), la modale ne s'affichera pas, le navigateur affichera ses propres messages d'erreur, et les champs invalides seront marqués en rouge avec la classe Bulma is-danger.

✓ Les fichiers JS/CSS ne sont chargés qu'une seule fois.

ℹ️ Astuce : Essayez de soumettre un formulaire avec des champs vides pour voir la validation en action.

Comment ça marche ?

  1. Lorsque vous cliquez sur "Soumettre", le JavaScript vérifie d'abord la validité du formulaire avec form.checkValidity()
  2. Si le formulaire n'est pas valide, form.reportValidity() déclenche l'affichage des messages d'erreur natifs du navigateur
  3. Les champs invalides sont marqués avec la classe is-danger de Bulma pour une mise en évidence visuelle
  4. La modale ne s'ouvre que si le formulaire est valide
  5. Lorsque vous cliquez sur "Envoyer" dans la modale, le formulaire est soumis avec form.submit()
